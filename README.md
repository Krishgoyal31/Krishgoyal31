**VYXORA** is *the home of ambitious developers*: a community platform where builders publish their work, get discovered, and team up on projects.

| Feature | What it does |
|:--|:--|
| 📤 **Project Publishing** | Share work with a cover image, GitHub repository, live demo link and full description. The publisher becomes the verified owner. |
| 👤 **Creator Profiles** | Public developer profile with avatar, bio, project count, total views and selected work. |
| 🔎 **Discovery** | Search creators by name or `@username`, and filter projects by category. |
| 🤝 **Collaboration** | Invites, join requests, open positions, team activity, analytics and ownership transfer. |
| 💬 **Messaging & Notifications** | Direct creator conversations, an official support channel and a unified activity feed. |
| 🔖 **Saved Library** | Bookmark projects worth returning to. |
| 🗨️ **Community Discussion** | Comment threads on every project. |
| 🔐 **Auth & Recovery** | Email or Google sign-in, profile editing, password change and a secure account-recovery flow. |

**VENOM** is an *industrial-grade intelligence collective* that bridges abstract cognition and high-performance execution, delivered as one unified platform of six AI modules.

| Module | What it does |
|:--|:--|
| 💬 **Neural Chat** | Context-aware conversational AI with multi-turn dialogue. |
| 🫀 **EmoCare** | AI emotional-wellness tracking using real-time facial and sentiment analysis. |
| 🛠️ **Forge IDE** | Multi-language cloud IDE with AI code completion, refactoring and collaboration. |
| ✍️ **Write** | Converts digital text into realistic handwritten documents via neural synthesis. |
| 🏗️ **Architect** | Describe a website in plain language and get production-ready code generated. |
| 🧪 **Quiz Generator** | Builds tests and knowledge assessments on any subject. |

> 🔐 **Privacy by design:** VENOM runs on a *bring-your-own* Gemini API key that is stored **only in your browser** (`localStorage`) and never sent to the VENOM servers. It is also installable as an app (PWA). Desktop is recommended for the full experience.
